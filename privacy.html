Política de Privacidad

Última actualización: 2026

Esta aplicación ("The Ink Engine") accede a la API de Pinterest únicamente para gestionar boards y pins de la cuenta del usuario autorizado. No se recopilan, almacenan ni comparten datos personales de terceros.

Los tokens de acceso se almacenan de forma segura y se usan exclusivamente para las operaciones solicitadas por el usuario. No se comparten con terceros ni se usan para fines publicitarios.

Para consultas, contactar al propietario de la aplicación.
